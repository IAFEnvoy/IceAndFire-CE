# One-way compatibility tags on 1.20.1

All Ice and Fire reads of `c:` or `forge:` tags now pass through mod-owned `iceandfire:compat/...` tags. This covers material checks, recipe inputs and unlock criteria, creature biome tags, structure biome tags and the Gorgon boss exemption. The existing optional source imports are preserved; biome unions are not broadened.

Vanilla defaults such as gravel, cobblestone, chests, string, glass, milk and iron now live directly in compat tags. Compat tags can optionally import either loader's material tags. An absent foreign tag does not make a compat tag fail to load.

Published `c:` and `forge:` tags contain only concrete Ice and Fire entries, so other mods can still find silver, witherbones, armor and tools. They do not reference each other or compat tags. The armor aggregate is an explicit list of this mod's armor, rather than importing foreign armor tags. Compat-only and third-party material entries are never exported back to the other namespace.

Run `python scripts/check_compat_tags.py` to validate the source tag graph and all external import boundaries. The script also accepts release JAR paths. It checks dependency cycles, optional foreign imports, concrete exports and recipe/advancement tag references.

The Fabric GameTest suite tests separate `c`, `forge` and compat-only silver markers, verifies their union and isolation, checks vanilla defaults and confirms that silver recipes accept both conventions. Chest fixtures verify that imports from foreign chest subtags retain dragon-break protection. Existing gravel/cobblestone/sand regression tests continue to exercise both namespaces. Marker entries belong to the test source set only and must not appear in release JARs.

A symbolic expansion comparison against the preceding source snapshot preserves all 119 existing gameplay and compat tag memberships, including arbitrary third-party contributions. This catches lost nested imports as well as changes to vanilla members. The old foreign armor aggregate now explicitly exports only this mod's own armor rather than aggregating other mods' equipment.
