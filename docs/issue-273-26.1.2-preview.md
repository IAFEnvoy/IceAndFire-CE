# Issue #273: Minecraft 26.1.2 preview

This first preview adjusts the attached plates with confirmed shell overlap:

- Fire, ice and lightning Dragonsteel armor: visor halves, shoulder sleeves and lower leg plates receive the same cube deformation as the base armor.
- Sea Serpent armor: shoulder sleeves receive the base armor deformation for every color.

The Dragonsteel visor front now projects 0.20 model pixels beyond the helmet shell, instead of sitting 0.25 pixels behind it. The existing armor padding, textures and equipment-slot selection are retained. Horns, spikes and fins keep their original dimensions. Dragon Scale armor and other armor families are outside this first visual trial.

## Verification

On 2026-11-13, the development client entered a fresh, isolated flat world and passed 24 geometry/model checks: 12 Dragonsteel item/slot cases, seven Sea Serpent shoulder cases and five existing deferred-model cases. Armor checks use the registered NeoForge item extensions and transformed polygon vertices, covering visor/plate clearance, unchanged Dragonsteel horns and absence of geometry from other equipment slots.

```powershell
# Java 25; also make Java 21 available to the Minecraft asset tools.
.\gradlew.bat '-Dorg.gradle.java.installations.paths=D:/Program Files/Microsoft/jdk-21.0.8.9-hotspot,D:/Program Files/Microsoft/jdk-25.0.0.36-hotspot' -PauditClientRegression runClient --offline --no-configuration-cache --console=plain
.\gradlew.bat build --offline --no-configuration-cache --console=plain
```

The final build must omit `-PauditClientRegression` so the test code is excluded. Logs are written to `build/issue273-client.log` and `build/issue273-build.log`; the client result is in `build/client-regression-runtime/client-regression-result.json`.

## Visual trial

Use `build/libs/26.1.2/iceandfire-2.2-issue273-preview.jar` in place of the existing Ice and Fire CE JAR in a Minecraft 26.1.2 instance, using the same dependencies.

Compare fire, ice and lightning Dragonsteel sets on armor stands, especially the visor, eye opening, shoulder shape and lower leg plates. Check the helmet from the front, side and below. Then wear a set and check standing, crouching and walking with the player's outer skin layers enabled. Check Sea Serpent shoulder sleeves from both the front and back.

These checks confirm client loading and geometric separation. On 2026-11-13, the user reported that the preview appeared correct in their visual trial. The automated result itself does not verify texture appearance, lighting or the final silhouette. No changes have been ported to 1.20.1 or 1.21.1 as part of this preview.
